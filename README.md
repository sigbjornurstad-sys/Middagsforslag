# Middag på bordet

En statisk middagsapp med hovedingredienser, glutenfrie tilpasninger, porsjonsmengder og handlelister.

## Bruk

Åpne `index.html` i en nettleser. Ingen installasjon eller bygging kreves.

## GitHub

Last opp alle filene i denne mappen til rotmappen i repositoriet. Behold filnavnene.

`index.html` inneholder utseendet. JavaScript-filene inneholder funksjoner og oppskriftsdata. `dinner.jpg` er illustrasjonsbildet.

Oppskriftskildene er lenket i appen. Utvalget er kontrollert 9. oktober 2026.
